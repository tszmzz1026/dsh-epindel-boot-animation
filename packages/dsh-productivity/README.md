# DSH 效率中心

主聊旁聊、本地长期记忆、目标待办、今日计划与复盘、全文搜索、文件检查点、上下文管理、清理指令与 MD 总结。入口位于侧栏底部，可按 Ctrl+Shift+F 打开。

记忆提供可编辑的 Markdown 文档与范围控制；模型须实际调用保存工具，面板显示成功、失败或拒绝。补整理按钮向当前会话发送明确请求。自动整理使用当前模型，不额外调用后台记忆模型，也不保证每句话都会保存。

带日期的待办同步到每日计划，保留手写计划和复盘。每天首次进入可提醒一次；主聊旁聊与原生会话对应，不复制成另一套聊天记录。

文件检查点只处理工作区内普通文件，带差异预览、确认回退与安全备份；上下文按完整轮次排除或恢复，保留原日志。压缩、清理和总结使用安装者自己的模型/API。

数据保存在 `DSH_HOME/plugin-data/dsh-productivity`，无账号或跨设备同步。当前验证环境为 Windows / DSH Desktop 0.12.0 / Harness 0.2.0-rc.2。代码采用 MIT 许可。本包没有角色图片、游戏动画、背景音乐或其他游戏素材。
