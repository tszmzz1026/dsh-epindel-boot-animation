# DSH 原创主题（dsh-glass-aurum）

纯 CSS 金紫液态玻璃、金色输入、代码配色、助手几何标记、工作台卡片和阅读排版。无游戏背景、角色头像、视频或音频，不请求外部媒体。

> **包名已从 `dsh-glass-theme` 改为 `dsh-glass-aurum`。** 市场上存在另一位作者发布的同名包 `dsh-glass-theme`（作者 `cnayu`，`1.0.2`），两者不是同一份代码。改用唯一包名后，市场升级或依赖解析不会再把本主题替换成别人的实现。旧包名请先停用或卸载。

本插件独立安装，只提供主题；推理滑块适配样式需要使用者已经安装兼容的推理选择器。本包不内置该第三方插件。

入口为右上角「主题」，也可在通用设置打开。支持配色、专注模式、减少动态效果与主题开关。最小化或托盘恢复保留当前页面。

## 壁纸

「主题」面板中的「壁纸」区域可以导入自己的图片或视频作为对话背景：

| 能力 | 说明 |
| --- | --- |
| 导入 | PNG / JPEG / WebP / AVIF / GIF / BMP 图片，MP4 / WebM / MOV / OGG 视频，单文件上限 512 MB |
| 浓度与模糊 | 0–100% 浓度、0–24 px 模糊，模糊时背景自动向外扩张，不会露边 |
| 填充 | 铺满裁切 / 完整显示 |
| 视频 | 静音开关、0–100% 音量、暂停 / 播放、循环播放 |
| 存储 | 文件由宿主写入 `DSH_HOME/plugin-data/dsh-glass-aurum/`，通过同源路由 `/plugins/dsh-glass-aurum/wallpaper` 读取，不占浏览器存储，清缓存也不会丢 |

壁纸文件只留在本机，不上传模型接口，也不会进入公开发行包。系统开启「减少动态效果」时视频不会自动播放。

## 头像与名称

可自行上传 PNG、JPEG 或 WebP 头像，拖动、缩放或调整水平与垂直位置后确认裁切；支持取消和恢复默认头像。助手名称可直接编辑，同步显示在主页与回复旁。头像和名称仅保存在当前设备的界面存储中，不上传到服务器或打进发布包。

## 按图片生成主题

本包**不包含**「根据一张图片生成主题」。这个能力留给使用者用自己的 DeepSeek Harness + API 实现，主题侧已经留好接入位置：

1. 生成结果只需要落到主题设置 `dsh.glass-theme.v1` 的 `palette` 字段，或在宿主 `theme.overrideTokens(id, pairs)` 中提供一套 `{ light, dark }` token；
2. 主色建议同时写入 `--ep-accent`、`--ep-accent-rgb`、`--ep-ink` 三个变量，玻璃面板与主按钮就会跟着变色；
3. 图片取色若交给模型，请把图片摘要或色值而不是整张原图发给 API，并在面板上明确提示这是模型生成结果。

## 安装

使用对应 DSH 的原生 CLI：`dsh plugin --profile web add link:<本目录绝对路径>`。当前已验证 Windows / Harness 0.2.0-rc.2；安装后按宿主提示重启。代码采用 MIT 许可。
